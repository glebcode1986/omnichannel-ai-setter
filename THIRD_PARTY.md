# Third-party References and Attribution Plan

Researching a repository does not mean code is copied from it.

Before adapting any source code, record:

- upstream repository URL;
- exact commit SHA;
- file(s) adapted;
- upstream license;
- required copyright/license notice;
- summary of modifications;
- confirmation that the license is compatible with our intended distribution.

## Current research references

- InstaAuto

- Senqo
- wacrm (`ArnasDon/wacrm`)

- official Meta Instagram/WhatsApp API documentation and examples

## Rule

Do not copy source from a repository whose license status has not been verified. Architectural ideas and public API patterns may be reimplemented independently.
